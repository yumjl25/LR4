## Описание заданий

### Задание 1: Решение нелинейного уравнения 

**Уравнение:** `x * ln(x+1) = 1`

**Точность:** ε = 10⁻⁴

Реализованы три метода уточнения корня:
- Метод половинного деления
- Метод Ньютона (касательных)
- Метод простых итераций

---

### Задание 2: Генератор Фибоначчи с запаздыванием 

Реализован генератор псевдослучайных чисел на основе метода Фибоначчи с запаздыванием.

**Формула:** Sₙ = (Sₙ₋ₐ ∘ Sₙ₋ᵦ) mod m

**Параметры:**
- a, b — лаги (запаздывания)
- m — модуль
- seed — начальные значения
- N — количество генерируемых чисел

**Поддерживаемые операции:**
- Сложение (+)
- Вычитание (−)
- Умножение (×)
- XOR (^)

---

### Задание 3: Обработка одномерного массива 

**Массив 1:** 15 случайных чисел в диапазоне [0, 100]

**Операции:**
- Поиск чётных элементов, стоящих после нечётных, и их сумма
- Поиск локальных минимумов (элемент меньше обоих соседей)
- Сортировка: чётные по возрастанию, нечётные по убыванию

**Массив 2:** 15 случайных чисел в диапазоне [100, 120]
- Определение самого частого элемента
- Поиск элементов, больше найденного элемента


---

### Задание 4: Методы голосования 

Реализованы два алгоритма определения победителя на выборах.

**Метод Борда:**
- Кандидаты получают очки в зависимости от места в голосе 
- Побеждает кандидат с максимальной суммой
- При ничьей выводятся все кандидаты-победители

**Метод Кондорсе:**
- Кандидаты сравниваются попарно
- Победитель — кандидат, побеждающий всех остальных
- Если возникает цикл (A > B, B > C, C > A), победитель не определяется
